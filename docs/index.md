# Penzene

An open-source, native desktop chemical structure editor, and a free alternative to ChemDraw.
It runs on macOS, Linux and Windows, and does its chemistry with [RDKit](https://www.rdkit.org).

![Penzene with aspirin](screenshot.png)

- **Draw fast** with the mouse or [the keyboard](keys.md): point at an atom and type `2` for a carbonyl or `a` for a phenyl.
- **Chemistry built in:** live formula and mass, stereo labels, a properties panel, structure checks, and names from PubChem.
- **Figures for papers:** ACS, RSC and JDP styles, reaction schemes, electron-pushing arrows, templates, and exports that reopen as editable drawings.
- **Works with ChemDraw:** open and save CDXML, and paste from ChemDraw.
- **Scriptable:** the same engine from [Python](python.md) and the [command line](cli.md).

Start with [Installing](install.md), then [Drawing](drawing.md).
