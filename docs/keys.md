# Keyboard shortcuts

Generated from Help → Keyboard Shortcuts in the app. Point at an atom or bond to make it the
*hotspot*, then type.


## Moving the hotspot

| Keys | |
|---|---|
| `←↑→↓` | atom → bond → atom; with **Shift**: atom → atom, bond → bond (with a selection: nudge it, below) |
| `Space` / `g` | select the hotspot's molecule / just its atom or bond |
| `Esc` | clear hotspot and selection |

## Atom: sprout

| Keys | |
|---|---|
| `1` / `0` | single bond, linear / cyclic mode (0 is longer on 2°/3° carbons) |
| `2` | acetyl (1°), C=O (2°), CH₂-acetyl (3°/aromatic) |
| `3` or `a` | phenyl |
| `4` / `5` | wedged / hashed methyl |
| `6 7 u v` | cyclohexane, cyclopentane, cyclobutane, cyclopropane (spiro on 2°) |
| `8 9 z` | methylidene, dimethyl / gem-dimethyl / isopropyl, alkyne |
| `k K` | sulfonyl, t-Bu |
| `.` / `j` / `J` | attachment point / η⁵-cyclopentadienyl / η⁶-benzene |

## Atom: label and marks

| Keys | |
|---|---|
| `c n/w o/q s p f l b i h` | C N O S P F Cl Br I H |
| `B S L` | B, Si, Li |
| `m e P A` | Me, Et, Ph, Ac |
| `O N F E Z` | OMe, NO₂, CF₃, CO₂Me, N₃ |
| `y/Y H Q M` | Boc, Cbz, Fmoc, MgBr |
| `x r` | X, R (generic atoms) |
| `+ −` | charge |
| `:` / `*` | lone pairs (0–3) / radical dot |
| `'` | atom-map number (next free, or off) |
| `Enter`, `=` or `t` | type a label: element, abbreviation (OMe, Boc, TBS…), SMILES or any text |
| `/` or `?` | atom properties |
| `Delete` | remove label (C stays), or delete a carbon |

## Bond

| Keys | |
|---|---|
| `1 2 3` | single, double, triple; **2** on a double bond swaps the side of its second line |
| `w` / `h`, `W`, `H` | wedged / hashed (press again to flip) |
| `a z` | fuse benzene / cyclopentadiene |
| `v 4–8` | fuse ring of that size (v = 3) |
| `9` / `0` | fuse chair cyclohexane (two orientations) |
| `d b y` | dashed, bold, wavy |
| `D` / `B` | dashed double / bold double |
| `i` | interaction: H-bond or contact, dotted, not a bond |
| `p` / `P` | partial bond forming or breaking / partial double (transition states) |
| `l c r` | double bond's second line left / centred / right |
| `f` | bring to front: bonds it crosses get a gap |

## No hotspot (Esc)

| Keys | |
|---|---|
| `x X j e t Space` | bond, chain, benzene, arrow, text, select tool |

## Selection

| Keys | |
|---|---|
| `←↑→↓` | nudge 1 pt; with **Shift** 10 pt |
| `Enter` | back to a hotspot on the selection |
| `Drag onto an atom` | merge (Select tool)  •  **Shift+drag** move straight; draw a bond at any angle |
| `Ctrl+←↑→↓` | duplicate across the next arrow that way (or alongside) |
| `Alt+← →` | rotate 15°  •  **Alt+drag** rotate freely • **double-click** select fragment, or edit text |
| `Shift+Alt+←↑→↓` | rotate 15° out of the page (3D), keeping stereo  •  **Shift+Alt+drag** freely |
